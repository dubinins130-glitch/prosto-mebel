# Просто мебель

Демонстрационный сайт компании «Просто мебель» из Благовещенска. Направление «По вашим размерам». Дизайн и разработка SLOY.

## Экраны

1. **«По вашим размерам».** Огромный заголовок, фото кухни в правой колонке. Там, где слово заходит на фото, оно меняет цвет. Размерные линии с числами в миллиметрах.
2. **Фото в натуральную величину.** При прокрутке окно фото растёт до полного экрана, на нём рисуются размеры и выноски.
3. **Что делаем.** Фото сжимается до окна, слева список направлений (кухни, шкафы, гардеробные, прихожие, детские). Прокрутка меняет фотографию и подпись кнопки под ней. Названия, фото и кнопка открывают соответствующий конфигуратор.

Все три экрана работают как одна закреплённая сцена с одним таймлайном: прокрутка в обе стороны даёт то же самое движение в обратном порядке. Код сцены: `src/components/stage.tsx`, стили: `src/app/globals.css`.

## Конфигураторы

Прямые адреса — `/kitchens/`, `/wardrobes/`, `/dressing-rooms/`, `/hallways/` и `/children/`. При переходах GSAP перемещает фотографию нужной категории, сохраняя её пропорции. «Вся мебель» и кнопка «Назад» восстанавливают выбранную категорию на третьем экране.

У каждого направления свой чертёж. Размеры вводятся вручную или ползунком. Настройки сохраняются при переходе между этапами и переносятся в демо-заявку. Стоимость уточняет менеджер. Демо-форма проверяет поля в браузере, а параметры можно скопировать отдельно. Подписи, поля и диапазоны размеров хранятся в `src/content/estimate.ts`.

## Запуск

```sh
npm ci
npm run dev
```

Откройте [localhost:3000](http://localhost:3000) (именно `localhost`, а не `127.0.0.1`). Проверка и статическая сборка:

```sh
npm run typecheck
npm run lint
npm run build
```

`npm run build` экспортирует сайт в `out/`. GitHub Actions собирает и публикует его при push в `main`. Для сборки под вложенным адресом можно задать `NEXT_PUBLIC_BASE_PATH=/prosto-mebel`.

Телефон, почту и адрес для локальной сборки можно задать в `.env.local` по `.env.example`.

## Загрузочная анимация

Показывается один раз за сессию, только на экранах шире 1100 px и без `prefers-reduced-motion`. Начинается сразу, когда готовы шрифты и главное фото, ничего не растягивается искусственно. Клик или любая клавиша пропускают её. На телефонах только короткое появление заголовка. Флаг сессии: `sessionStorage["pm-intro"]`.

## Размеры и подписи

Числа на фото («2 640 мм», «900 мм», «Столешница · 38 мм») в демо **примерные**, на странице это подписано. В версии для клиента их заменяют размерами его настоящих работ: `src/content/site.ts` (`dimensions`) и подписи в `src/components/stage.tsx`.

## Фотографии

Только настоящие лицензионные фото (Unsplash и Pexels), без генерации. Авторы, ссылки и лицензии: [IMAGE_SOURCES.md](IMAGE_SOURCES.md). Для продажи фото заменяют работами клиента.

## Для разработки

В режиме `npm run dev` на `window.__stage` доступны таймлайн и триггер сцены. Параметр `?nosmooth` отключает сглаживание прокрутки: так удобно сверять состояния. В production этих отладочных точек нет.

Для демонстрационной версии в метаданных установлен `noindex` (`src/app/layout.tsx`).
