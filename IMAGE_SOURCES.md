# Источники фотографий

На сайте показаны фотостоковые примеры интерьерных решений. В подборку вошли работы фотографов Unsplash и Pexels. В проекте используются локальные адаптивные версии WebP, включая отдельное кадрирование обложки для телефона.

Обложка каждой категории использует тот же снимок, что и её окно на главной. Это `cover-*.webp` для кухонь, `shkafy-*.webp` для шкафов, `closet-*.webp` для гардеробных, `prihozhie-*.webp` для прихожих и `detskie-*.webp` для детских.
